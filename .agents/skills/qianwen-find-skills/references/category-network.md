# network · 网络

Use for network reachability, network-product inspection, gateways, ingress migration, API gateways, and edge deployment.

| Theme | Core queries | High-signal anchor queries |
| --- | --- | --- |
| Reachability | 可达性、网络路径 | NIS, reachability |
| Network inspection | 网络巡检、网络健康 | inspection, health |
| Network products | 负载均衡 | EIP, NAT, CEN, TR |
| Connectivity | VPN、丢包、带宽 | SAG, tunnel |
| Ingress migration | Ingress、迁移 | Nginx, Higress |
| API gateway | 网关 | API Gateway |
| Edge deployment | 边缘、部署 | ESA, Pages, edge |

Use `security` when the dominant goal is protection such as DDoS defense, firewall policy, or threat detection.
