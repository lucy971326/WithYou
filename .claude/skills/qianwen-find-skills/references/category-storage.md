# storage · 存储

Use for SLS queries, PDS workspaces and search, OSS operations, and Cloud Backup.

| Theme | Core queries | High-signal anchor queries |
| --- | --- | --- |
| Log query | 日志、分析 | SLS, SPL |
| Drive workspace | 网盘、工作空间、挂载 | PDS, drive |
| File sync | 文件、同步、下载 | PDS, sync |
| File search | 检索、文搜图 | PDS, search |
| Object upload | 上传 | OSS, upload |
| Storage diagnosis | 网络探测、带宽、软链接 | OSS, probe |
| Backup | 备份 | Cloud Backup, backup |

Use `data` when the request is about databases, ETL, data governance, or queryable datasets rather than durable byte storage.
