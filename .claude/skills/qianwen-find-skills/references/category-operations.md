# operations · 运维

Use for cross-product resource inventory, cloud-governance evaluation, QianWen authentication, and Skill CLI troubleshooting.

| Theme | Core queries | High-signal anchor queries |
| --- | --- | --- |
| QianWen auth | 认证、401 | API Key, QIANWEN_API_KEY, auth |
| Endpoint setup | Endpoint、凭证 | endpoint, credential |
| Resource inventory | 资源盘点、资源搜索 | inventory |
| Cloud governance | 云治理、治理报告 | governance |
| CLI guidance | CLI、报错、调试 | troubleshooting |
| Plugin management | 插件、版本 | plugin |

Use `compute` for ECS/Linux diagnosis or deployment, ACK, and E-HPC. Use `security` for RAM authorization, WAF, firewall, and security incidents.
